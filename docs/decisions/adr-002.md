# ADR-002 — Starter philosophy

**Status:** Accepted

**Decision:** starters contain zero code; one starter per capability-provider pair; `starter-core`
is the only implicit starter.

**Why:** code in starters becomes un-excludable; per-provider starters keep classpaths minimal and
choices explicit.

**Consequence:** more starter POMs; trivially cheap.

See also: [extension model](../concepts/extension-model.md) · [platform BOM](../reference/bom.md).
