# ADR-004 — Auto-configuration as the only wiring mechanism

**Status:** Accepted

**Decision:** all platform behavior activates via `@AutoConfiguration` + conditions; no
`@ComponentScan` into platform packages, no `spring.factories` legacy, no programmatic registrars
beyond what conditions require.

**Why:** deterministic, debuggable (`--debug` report), AOT-analyzable, overridable by construction.

**Consequence:** condition-matrix tests are mandatory (§10).

See also: [conventions](../concepts/conventions.md) · [extension model](../concepts/extension-model.md).
