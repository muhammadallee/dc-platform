# ADR-005 — Release-train versioning

**Status:** Accepted

**Decision:** single version across all platform artifacts; SemVer on the train; no per-module
versions.

**Why:** eliminates the compatibility matrix; one tested set; one upgrade lever.

**Consequence:** a one-line fix ships a whole patch train — accepted; cheap with automated releases.
