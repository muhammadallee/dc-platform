# ADR-009 — Why not a God Framework

**Status:** Accepted

**Decision:** no `platform-all`, no mega-core, `core-api` capped in size.

**Why:** transitive bloat, universal blast radius, CVE surface, native-image hostility, and the
coupling ratchet: every convenience added to a god module is permanent.

**Consequence:** teams add 3–8 starters instead of 1 artifact — the archetype writes those lines for
them.
