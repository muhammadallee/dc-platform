# Labs

Each lab takes you from nothing to a running service generated by the archetype, showing one capability at work.
The commands are exactly the ones `tooling/labs/run-lab.sh <lab>` runs on every phase's final commit, so they work as
written.

## What you need

- JDK 25 and Maven 3.9 on the path.
- `curl`.
- This repository checked out. Nothing is published yet, so each lab starts by building the platform into a local
  Maven repository of its own (about three minutes, 1–2 GB of disk). It copies third-party artifacts from your
  `~/.m2`, so build the repository once online first (`mvn install -DskipTests`).
- Docker only where a lab says so.

Set `PLATFORM_HOME` to your checkout before you start:

```bash
export PLATFORM_HOME=/path/to/dc-platform
```

## Order

| Lab | Capability | Infrastructure |
|---|---|---|
| [First service](first-service/index.md) | core + errors | none |

Later labs (logging and observability, data, outbox, messaging) arrive with their capabilities.

## Running a lab automatically

```bash
bash tooling/labs/run-lab.sh first-service
```

It runs every command in a fresh directory under `~/dc-labs/`, checks every expected result, stops whatever the lab
started, and exits 0 only if everything passed.
