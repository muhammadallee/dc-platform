# Upgrade notes — 0.2.0

> Train `0.2.0` (development: `0.2.0-SNAPSHOT`). This is the **M2 milestone**: the golden path is
> complete — a service generated from the archetype builds, boots, and is probed end to end.

## ACTION REQUIRED

None. `0.2.0` is additive over `0.1.0`.

## Highlights

- **Golden-path complete (M2).** REST + errors + logs + metrics + tracing + security + messaging +
  JPA + tests + docs, generated by the [service archetype](../quickstart.md) in under 10 minutes.
- **Config metadata everywhere.** Every `@ConfigurationProperties` now emits
  `spring-configuration-metadata.json`, so IDEs autocomplete every `dc.platform.*` key and the
  [properties reference](../reference/properties.md) is generated from code.
- **Documentation as a product.** Generated [properties](../reference/properties.md),
  [error-code](../reference/error-codes.md), and [BOM](../reference/bom.md) references; the ten
  [ADRs](../decisions/adr-001.md); the four [runbooks](../runbooks/local-dev.md); and a completeness
  gate that fails the build if a property is undocumented or a starter has no capability page.

## Deprecations

None in this train.

## How to upgrade

Follow the [upgrade runbook](../runbooks/upgrade.md): bump the one version, run the upgrade checker,
`mvn verify`, and smoke-test locally.
