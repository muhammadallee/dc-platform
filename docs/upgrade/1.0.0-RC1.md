# Upgrade notes — 1.0.0-RC1

> Train `1.0.0-RC1` (development continues on `1.0.0-SNAPSHOT`). This is the **M3 milestone** and the
> release candidate for `1.0.0`: the full capability catalog, the documentation site, four runnable
> examples, and a local-first release pipeline are all in place. Soak this RC, then cut `1.0.0`.

## ACTION REQUIRED

None. `1.0.0-RC1` is additive over `0.2.0`.

## Highlights

- **Four reference examples** ([examples](../examples.md)): `example-minimal` (the platform floor),
  `example-golden-path` (the canonical service — REST + validation + security + OpenAPI +
  observability + JPA + messaging + cache + resilience + audit over an `orders` domain),
  `example-extension-provider` (a custom `ObjectStore` certified by the storage TCK, proving the
  [extension model](../concepts/extension-model.md)), and `example-event-driven` (producer/consumer
  with `@EventHandler` retry/DLQ).
- **Smoke matrix.** `tooling/scripts/smoke-matrix.sh` boots the golden-path service across curated
  capability toggles and asserts `/actuator/platform` against a checked-in expectation table.
- **Startup-budget guard.** The golden-path example fails its build if cold-start wall-clock regresses
  more than 15% past a comment-governed baseline.
- **Release automation.** `tooling/scripts/release.sh <version> [--rehearse|--notes-only]` runs the
  gates, generates release notes from conventional commits and an aggregate japicmp compatibility
  report, and either stages to a `file://` repo (rehearsal, `-Plocal-release`) or tags the train;
  `release.yml` performs the real deploy on tag push. See the [release runbook](../runbooks/release.md).

## Messaging note

Kafka remains deferred until the infrastructure supports it. The real-broker example and profile
target **RabbitMQ**; the messaging API is transport-agnostic, so adopting Kafka later is a starter
swap, not a code change.

## Deprecations

None in this train.

## How to upgrade

Follow the [upgrade runbook](../runbooks/upgrade.md): bump the one version, run the upgrade checker,
`mvn verify`, and smoke-test locally.
